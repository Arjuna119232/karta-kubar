## B. KOREKSI TERHADAP BRIEF (premis yang salah / berisiko)

1. **`lib/shared/` TIDAK ADA.** Struktur repo: `lib/` = app warga (69 file),
   `apps/mitra/` = app mitra. Tidak pernah ada `packages/` atau `apps/` di repo
   warga. Reuse yang nyata = design token warga
   (`lib/core/theme/app_colors.dart`, `app_spacing.dart`, `app_shadows.dart`,
   `app_motion.dart`) → di-port ke `apps/mitra/lib/core/theme/`.
2. **`flutter_foreground_task` TIDAK dipakai.** Alasannya teknis, bukan gaya:
   notifikasi ONLINE yang tidak bisa di-swipe **sudah terbukti jalan** lewat
   foreground service milik geolocator (`ForegroundNotificationConfig(setOngoing: true)`).
   Menambah plugin kedua = dua foreground service = dua notifikasi permanen
   yang saling kenak-kanakan + satu service yang tidak bisa dimatikan.
   Brief menyebutnya; gwlewati demi kestabilan.
3. **Package id `id.kuninganbarat.kunbarmitra` ≠ id yang terpasang**
   (`id.kunbar.kunbar_mitra` v1.3.0). Mengganti = **wajib uninstall** app lama
   dulu (tanda tangan & package berbeda). Data demo hilang, tidak masalah.
4. **Supabase masih KOSONG.** Semua 15 tabel balasan 404 `PGRST205` —
   termasuk `profiles` milik app warga. Artinya `supabase/schema.sql`
   belum pernah dijalankan. Selama belum dijalankan, "sinkron dengan APK Warga"
   **tidak bisa dibuktikan** — tidak ada data untuk disinkronkan.
   SQLException tidak bisa gw jalankan dari HP (butuh akses postgres/service_role).
   File SQL sudah disiapkan: jalankan di Dashboard > SQL Editor.
5. **Verifikasi KTP/SIM/STNK otomatis TIDAK MUNGKIN.** Tidak ada API publik
   KemenPolhukraf/PBpJS. Yang bisa dibangun: unggah foto dokumen + status
   `pending/verified/rejected` + verifikasi manual oleh admin di web panel.
   Auto-OCR (ML Kit) baru bermakna kalau adminnya tidak ada.
6. **`flutter doctor` / `flutter analyze` lokal tidak bisa dijalankan** —
   Flutter SDK tidak ada di Termux (bukan PC). Oracle satu-satunya =
   GitHub Actions. `flutter analyze` sengaja non-blocking; target "0 warning"
   berarti membersihkan deprecation yang memang ada
   (`anonKey`→`publishableKey`, `withOpacity`→`withValues`,
   `DropdownButtonFormField.value`→`initialValue`).
